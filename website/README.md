# Dueproof website

Plain HTML, CSS and a little JavaScript — no build step. Serve the folder with
any static host; for GitHub Pages, publish this `website/` folder.

Preview locally:

```bash
python3 -m http.server --directory website 8090
```

`assets/site.css` holds the design tokens at the top: ink `#14213D`, page
`#F3F5F8`, stamp violet `#5A3FC0`, marker yellow `#FFE066`. Type is Anek (Ek
Type), whose Indic families render the language samples.
