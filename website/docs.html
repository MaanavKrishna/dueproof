Install

Python 3.12 or newer and Tesseract. Five minutes on a laptop.

Full instructions, including Docker and the translation model

# macOS: brew install tesseract tesseract-lang # Ubuntu: sudo apt install tesseract-ocr tesseract-ocr-hin $ git clone https://github.com/MaanavKrishna/dueproof $ cd dueproof $ python3 -m venv .venv $ .venv/bin/pip install -e . $ .venv/bin/dueproof users add you@example.org --admin $ .venv/bin/dueproof serve
